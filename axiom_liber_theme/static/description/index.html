Liber Web Design Layer

Variant 003 — The Hybrid Builder

A single, upgrade-safe module that brings brand palettes, fonts, conversion-focused snippets, and SEO rich-result schema to the Tooling Components and RBC Industrial websites. It layers on top of the existing sites — it does not replace the current theme.

In the box

  • Two brand palettes — selectable per website from the Theme editor.
  • Brand fonts — Inter and a distinct heading treatment, pre-loaded.
  • Five snippets — Trust Badges, Conversion CTA, Spec Table, Cross-Brand Compatibility, and Author Bio.
  • Product schema — schema.org Product/Offer/MPN JSON-LD on every product page.
  • Breadcrumb schema — schema.org BreadcrumbList JSON-LD on every page.

Non-destructive

Regular Website module, not an Odoo Theme. Install and uninstall without touching your current design or content. Every visible element reads from the active brand palette, so re-branding is a matter of changing ten hex values.
