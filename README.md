# liber

Odoo 17 addons for the Liber websites and backend.

## Modules

| Module | Purpose |
| --- | --- |
| `website_blog_auto_translate` | Translates blog posts for free (no API key) when a visitor switches the website language, and re-translates them when the content changes. See its [README](website_blog_auto_translate/README.md). |

## Python dependencies

Installed from `requirements.txt`:

```
pip install -r addons/liber/requirements.txt
```
