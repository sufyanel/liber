    1. Executive Summary

    The Problem

    > "I don't like how the blogs and new pages look and don't want to keep editing them."

    Odoo's default blog and page templates are generic — they work for all industries but excel at none. The fix is not more manual editing (a treadmill). The fix is a custom theme module deployed via Odoo.sh that globally overrides the default templates, SCSS variables, and snippet architecture. Build it once, deploy across all sites.

    The Process

    1. Research phase: 7+ sources collected into NotebookLM for synthesis

    2. Design phase: 3 distinct design variants created, each optimized for a different B2B use case

    3. Brand alignment: Each variant assessed against existing brand guidelines for Tooling Components and RBC Industrial

    4. Technical build: Odoo v17 custom theme module scaffolded and pushed to GitHub

    Key Finding

    None of the three design variants fully matches either brand's published guidelines. The next step is to select a variant direction and apply correct brand colors.

    2.4 ThunderClap

    Source: "#10 Best B2B Website Designs of 2026 That Increase Conversions"

    URL: https://www.thethunderclap.com/blog/best-b2b-website-designs-increase-conversions

    Key Findings — The C.O.N.V.E.R.T. Framework:
    PrincipleMeaningApplied In
    -------------------------------
    **C — Clarity in Value Proposition**User must understand who you are and what you offer in <3 secondsHero section with clear positioning
    **O — Outcome-Focused Layout**Layout should guide toward a measurable outcome (quote, demo, contact)CTAs at natural breakpoints in content
    **N — Navigation Simplicity**Reduce cognitive load; don't make users thinkClean top nav, breadcrumbs, sticky elements
    **V — Value Visibility**Key differentiators must be immediately scannableTag badges, author credentials, trust signals
    **E — Experience Consistency**Same design language across all pages and devicesCentralized SCSS variables, reusable components
    **R — Real Social Proof**Case studies, testimonials, certifications integrated throughout all pagesAuthor bio block, certification badges
    **T — Testing-Driven Optimization**Iterate based on data, not assumptionsDesign is structured for A/B testing (component-based)
    Excerpt:

    > "Your website doesn't have to suck. Clarity over cleverness. Outcome-focused messaging, not feature lists."
