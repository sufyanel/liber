Product Variant Combination Fix

This is a one-time data-fix utility, not a permanent customization. Install it, run its scheduled action once, confirm the affected products are clean, then uninstall it. It adds no fields and owns no other data of its own.

What it fixes

A product variant's defining combination should only ever contain values from always/dynamic attributes. Some existing variants also carry values from "Never" (no_variant) attributes in their combination - most likely left over from a time those attributes were configured differently. Because of that, Odoo can no longer match those variants against a new sale or purchase order for the same real product, and creates a brand new duplicate variant instead of reusing the existing one.

What running it does

One run scans the whole database for every product template that actually has this corruption - there is no list to maintain and nothing to schedule again later. For each one found, it keeps the oldest variant per real combination, whether or not a duplicate has already been created for it: moves any sale or purchase order lines pointing at a newer duplicate onto the kept variant, deletes the duplicate, and removes the stale attribute links so future orders match it correctly. If a duplicate still has other references (stock moves, invoice lines) or its order can't be edited (locked/invoiced/delivered), it is left in place and logged for manual review - that does not stop the run from fixing every other affected product.

Usage

Go to Settings > Technical > Scheduled Actions > "Fix Polluted Variant Combinations" and click Run Manually. It does not run on a schedule - one run is meant to catch everything currently affected.
